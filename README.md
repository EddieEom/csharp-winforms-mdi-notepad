## 담당 범위

수업의 요구사항을 바탕으로 부모·자식 폼, 메뉴 이벤트, 파일 열기·저장, 글꼴·배경색 변경을 구성한 학습 프로젝트입니다. 코드 작성 도구별 기여율은 기록이 없어 수치로 제시하지 않습니다.

## 개발 과정

### 메뉴를 누르면 어느 문서가 바뀌어야 할까

여러 창을 여는 것에서 끝나는 것이 아니라 현재 선택한 문서의 편집기를 찾아야 했습니다. 부모 폼에서 활성 자식 폼을 구하고, 자식 폼의 `Editor`를 통해 편집 기능을 적용하도록 구성했습니다.

파일 저장도 문서 내용과 해당 문서의 경로를 함께 다뤄야 했습니다. 자식 폼마다 `FilePath`를 두어 문서와 저장 위치를 연결했습니다.

### 시간 갱신과 화면 스레드

시간 표시용 스레드에서 UI를 갱신할 때는 `BeginInvoke`를 통해 폼 쪽으로 작업을 전달했습니다. 백그라운드 작업과 화면을 다루는 코드를 구분하는 연습이었습니다.

별도의 장애 재현 기록이 없어 실제로 겪었다고 확인할 수 없는 예외나 해결 시간을 추가하지 않았습니다.

## 코드와 확인 범위

- [MainForm.cs](MDI_Test/MainForm.cs): 활성 문서 선택, 메뉴·파일·시간 갱신
- [Form2.cs](MDI_Test/Form2.cs): 문서 편집기와 파일 경로
- [samples](samples): 파일 열기·저장에 사용한 텍스트

인쇄 메뉴는 대화상자 연결 범위입니다. 실제 페이지 구성과 출력까지 완성한 기능으로 설명하지 않습니다. 위 화면은 기존 개발 당시 캡처입니다.

## 실행 방법

Windows, Visual Studio, .NET Framework 4.7.2 개발 도구를 준비하고 `MDI_Test.slnx` 또는 `MDI_Test/MDI_Test.csproj`를 열어 실행합니다.
